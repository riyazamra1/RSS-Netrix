# Security Policy

## Reporting a vulnerability

Do not publish exploit details, credentials, private keys, personal data or working proof-of-concept attacks in public issues.

Please contact Razeen Secure Solution through an independently verified official support channel and include:
- A concise description and impact
- Affected version/commit
- Reproduction steps that do not expose real credentials or third-party data
- Suggested mitigation, if known

Allow reasonable time for investigation and remediation before public disclosure.

## Scope

Security-sensitive areas include SSH host-key verification, credential storage, private-key handling, terminal logging, SFTP transfers, tunnel lifecycle, encrypted sync, update mechanisms and build/release workflows.

Never test against systems without explicit authorization.
